# 🌍 Adventure Hub

It is a travel blogging platform developed collaboratively, allowing users to explore, share, and document their travel adventures. With an interactive and user-friendly interface, it provides a central space for travel lovers to post their journey experiences, upload photos, and read about new places.

## 📌 Overview

Adventure Hub lets users:

- Share travel stories with images
- Discover adventures by others
- Maintain a digital diary of destinations visited

This platform was built using **core web technologies (HTML, CSS, JS)** on the frontend and **PHP with MySQL (via XAMPP)** on the backend for data storage and handling.


## 🚀 Features

- 📝 Post travel experiences with title, description, and images  
- 🗃️ Display a feed of all travel stories  
- 🔍 Search or browse adventures  
- 📸 Image upload with each post  
- 📌 Clean and responsive user interface  
- 🧭 Discover new places through shared adventures  



## 🛠️ Tech Stack

| Layer       | Technology       |
|-------------|------------------|
| Frontend    | HTML, CSS, JavaScript |
| Backend     | PHP              |
| Database    | MySQL (PHPMyAdmin via XAMPP) |
| Hosting (Local) | XAMPP Server |

## 📦 Getting Started (Local Setup)

### Prerequisites

- XAMPP installed (Apache + MySQL)  
- A web browser  
- Basic understanding of PHP and SQL

### Installation Steps

1. Clone or download the repository:
   ```bash
   git clone https://github.com/chesta-tak/adventure_hub.git

2. Move the folder to your XAMPP htdocs directory:

   C:/xampp/htdocs/adventure_hub

3. Start Apache and MySQL from the XAMPP Control Panel

4. Import the database:
 
 - Open http://localhost/phpmyadmin

 - Create a new database named adventure_hub

 - Import the database.sql file from the db/ folder

5. Visit the site in your browser:

   http://localhost/adventure_hub/index.html
